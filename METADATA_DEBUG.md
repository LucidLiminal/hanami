# Debug de géneros — v39

Cuando `genre` llega vacío, la ficha muestra **Géneros no recibidos · abrir diagnóstico**. El informe copiable incluye URL pública y resuelta, tamaño del HTML, slugs y hosts candidatos, cada endpoint probado, estado/error, claves del payload y número de géneros detectados. También se imprime en Vercel como `[Hanami metadata debug]`. No incluye cookies, tokens ni cuerpos completos de respuestas.
