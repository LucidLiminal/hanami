# Manifiestos de integridad

## Manifiesto actual

`current/V150_FILE_MANIFEST.sha256` corresponde a esta estructura del proyecto y se regenera en cada entrega de este árbol. Verifícalo desde la raíz:

```bash
sha256sum -c checksums/current/V150_FILE_MANIFEST.sha256
```

## Manifiestos históricos

`archive/` conserva sin alterar los manifiestos de v144 a v149. Son evidencia de sus entregas originales y no deben ejecutarse contra este árbol reorganizado, porque sus rutas reflejan la disposición histórica de los archivos.

La comprobación del ZIP entregado se publica junto al archivo como un SHA-256 separado.
