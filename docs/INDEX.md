# Índice de documentación

La raíz del repositorio conserva solo los archivos operativos y de configuración. La documentación de producto y mantenimiento vive bajo `docs/`; los manifiestos SHA-256 viven bajo `checksums/`.

## Estructura

| Ubicación | Contenido |
| --- | --- |
| [`overview/`](overview/) | Visión general, identidad visual, contrato y avisos de terceros. |
| [`features/`](features/) | Documentación por área: Biblioteca, lector, grupos, Explorar, navegación y migración. |
| [`operations/`](operations/) | Operación, PWA, overlays y configuración. |
| [`releases/`](releases/) | Hotfixes y validaciones por entrega. |
| [`reference/`](reference/) | Referencias complementarias. |
| [`ROOT_FILES_RELOCATION.md`](ROOT_FILES_RELOCATION.md) | Inventario completo de archivos trasladados desde la raíz. |

Los manifiestos actuales e históricos se describen en [`../checksums/README.md`](../checksums/README.md).
