# Port de Actualizaciones Inteligentes de Mihon

## Funciones auditadas
1. El reloj de arena solo es configurable cuando la obra pertenece a Biblioteca.
2. Etiqueta: No aplicable, Pronto o número de días hasta la próxima comprobación.
3. Color destacado cuando se utiliza un intervalo personalizado.
4. Cálculo automático con la mediana de fechas recientes: 3 publicaciones para listas cortas y hasta 10 para largas.
5. Intervalo predeterminado de 7 días si faltan fechas y límite de 28 días.
6. Aumento progresivo del intervalo si una serie deja de cumplir su ritmo.
7. Intervalo personalizado de 1 a 28 días.
8. Actualizar ahora omite la espera programada.
9. Actualización de Biblioteca con exclusiones inteligentes y categorías.
10. Actualización opcional de metadatos y contador de Actualizaciones.

## Pantallas y subpantallas
- Diálogo principal de Actualizaciones inteligentes.
- Selector Predeterminado inteligente / Intervalo personalizado.
- Selector móvil de días.
- Análisis del cálculo, ventana, intervalo, próxima comprobación y motivo de omisión.
- Ajustes generales de restricciones inteligentes.
- Selector de categorías incluidas y excluidas.
- Resultado de actualización de Biblioteca con actualizadas y omitidas.

El botón conserva el toque simple de Mihon; Mihon no le asigna pulsación larga. La estructura funcional procede de Mihon y la presentación visual sigue siendo Hanami.
