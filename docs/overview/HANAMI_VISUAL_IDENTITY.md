# Frontera visual del port

Mihon se usa únicamente como referencia para arquitectura de información, colocación funcional y gestos. Su identidad visual no se porta.

La interfaz conserva la identidad Hanami: negro neo-noir, violeta `#9a49d8`, verde ácido `#b8ec96`, rojo `#e93c54`, papel `#ebe6d8`, textura/grano, tipografía editorial, bordes rectos, sombras desplazadas y composición de fanzine.

La ficha mantiene la colocación funcional solicitada —barra, cabecera, acciones, descripción, etiquetas y capítulos— sin adoptar el rosa, las píldoras, la suavidad o el lenguaje visual de Mihon.
