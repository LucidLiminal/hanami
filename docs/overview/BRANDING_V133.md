# Crimson Knot — identidad visual v133

Esta revisión sustituye la identidad violeta de Hanami por una interfaz nocturna cálida, basada en el logo de nudo y agujas proporcionado para el proyecto.

## Paleta

| Uso | Color |
| --- | --- |
| Carmesí principal | `#9A3F3F` |
| Arena / acento | `#E6CFA9` |
| Marfil de texto | `#FBF9D1` |
| Terracota secundaria | `#C1856D` |
| Tinta de la interfaz | `#170B0D` |

## Recursos actualizados

- `public/assets/hanami-knot-logo.png`: logo recortado con fondo transparente para la cabecera.
- Iconos PWA, Apple Touch y favicon regenerados con la nueva marca.
- `manifest.webmanifest`, meta `theme-color` y el nombre de caché del service worker actualizados para forzar la renovación de recursos.

El logo se mantiene accesible: la imagen decorativa no repite texto y el botón de inicio conserva una etiqueta legible por lectores de pantalla.
